# Adding photos to the website

Photos appear on the site automatically. Put a file in the right folder with
the exact name below, commit and push. No code changes are needed. Until a
photo is added, the page shows a plain green frame (with initials for the
doctors).

Accepted formats: `.jpg`, `.jpeg`, `.png`, `.webp` or `.avif`.

## Doctors — `public/images/doctors/`

| File name | Shown on | Best shape |
|---|---|---|
| `dr-sanjeev-agarwal.jpg` | Home, Doctors | Portrait, 4:5 (e.g. 1200 × 1500) |
| `dr-manisha-agarwal.jpg` | Home, Doctors | Portrait, 4:5 (e.g. 1200 × 1500) |

Use a well-lit photo with a plain background, the doctor facing the camera,
head and shoulders visible.

## Tips

- Keep each file under about 500 KB. Resize large phone photos to about
  1600 px wide before adding them.
- Take photos in daylight, with rooms tidy and no patients visible.
- The photo is cropped to fill its frame, so keep the subject in the centre.

- `nabh-badge.svg`: NABH pre-accreditation badge
